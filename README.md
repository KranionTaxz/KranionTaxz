Uma experiência do roblox que está em desenvolvimento por mim!

[Ideia do jogo]

Os jogadores enfrentam gatos de outra dimensão, cada partida ocorre em mapas diferentes. O mapa é escolhido através de uma votação.
O jogador recebe pontos visto o seu desempenho durante a partida, como, sobrevivência até o fim do timer, quantidade de gatos eliminados e salvando outros jogadores.
Os gatos aparecem na partida após 20 segundos de preparo, eles saem de um portal, ao qual terá 3 pontos aleatórios que podem aparecer durante cada partida.
Para evitar problemas com o roblox, os gatos vão ter aparência modificada, com transformações, para deixarem menos parecidos com gatos da vida real.

❗ O JOGO AINDA AINDA ESTA EM DESENVOLVIMENTO ❗
